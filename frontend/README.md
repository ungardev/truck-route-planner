# Truck Route Planner - Frontend

Frontend React para la aplicacion de planificacion de rutas para camioneros.

## Requisitos

- Node.js 18+
- npm 9+

## Instalacion

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

Abre http://localhost:5173 en tu navegador.

## Variables de Entorno

- `VITE_API_URL`: URL del backend Django (por defecto: http://localhost:8000)
